This directory is reserved for local Quran data imports.

Expected files:
- hafs.json
- warsh.json
- qalun.json

Each file should contain a list of objects in the following format:
[
  {"surah_number": 1, "surah_name": "الفاتحة", "ayah_number": 1, "text": "بسم الله الرحمن الرحيم"}
]

No fabricated Quran text is bundled here. Import your verified local dataset into these files.
